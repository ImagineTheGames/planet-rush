### INTERPRETATION
The allocator control plane (/health, /regions, /rooms/:code/join) answers as clean JSON and is UP.
But POST /rooms returns 200 text/plain '"Planet Rush match server..."' — the bare gameserver's
WebSocket root banner — with NO access-control-allow-origin header. That is the Fly fly-replay
misroute: the allocate POST is replayed to a gameserver Machine instead of being handled by the
allocator, so no JSON room code is minted AND no CORS header is present. A browser fetch() therefore
fails CORS before reading any body -> allocator-client returns 'network' -> the client shows
'Can't reach the servers'. No room code can be minted on the live deploy. Deploy defect, not netcode.
